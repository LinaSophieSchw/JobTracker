Jedes «Speichern» = Stelle speichern + Arbeitsweg über OpenRouteService neu berechnen. Scheitert die Berechnung, wird trotzdem gespeichert.

Was es dafür alles braucht

Abgeleitet aus den Screens. Die Backend-Aufrufe sind mein Vorschlag nach eurer Konvention /api/…; grün = existiert schon im Code.

Im Hintergrund, ohne eigenen Button: Adressen → Koordinaten → Route (OpenRouteService), nur im Backend, mit Zeitlimit; API-Schlüssel nur serverseitig.

Meldungen in der App

Keine Erfolgs- oder Hinweismeldungen. Fehlermeldungen nur, wo Use Case 1 und das Datenmodell sie verlangen, je ein kurzer Satz. Den Wortlaut legt Use Case 1 fest; die Texte im Prototyp sind nur Beispiele.

FallGrundlageWortlaut
